## 🌟 Overview

Transformers is a comprehensive full-stack AI-powered fitness and wellness web application that provides personalized workout plans, nutrition guidance, and 24/7 AI health coaching. Built with modern technologies and designed for scalability and production readiness.

### Why Transformers?

- 🤖 **AI-Powered**: Leverages Groq's LLaMA-3.3-70B for intelligent workout and nutrition plan generation
- 📱 **Responsive Design**: Beautiful UI that works seamlessly across all devices
- 🎯 **Personalized**: Tailored plans based on your health assessment and fitness goals
- 💬 **AROMI AI Coach**: 24/7 AI assistant for motivation, guidance, and support
- 📊 **Progress Tracking**: Comprehensive analytics and visualizations
- 🏆 **Gamification**: Achievements, streaks, and charity contributions
- 🔗 **Integrations**: YouTube exercise videos, Spoonacular recipes, Google Calendar sync

## 🚀 Quick Start

### Prerequisites

- Python 3.9+
- Node.js 18+
- Groq API Key (required) - [Get it here](https://console.groq.com/)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/transformers.git
cd transformers
```

2. **Setup Backend**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. **Configure Backend Environment**
Create `backend/.env`:
```env
DATABASE_URL=sqlite:///./transformers.db
SECRET_KEY=your-secret-key-change-this
GROQ_API_KEY=your-groq-api-key
FRONTEND_URL=http://localhost:5173
```

4. **Start Backend Server**
```bash
uvicorn main:app --reload
```
Backend runs at: http://localhost:8000

5. **Setup Frontend**
```bash
cd ../frontend
npm install
```

6. **Configure Frontend Environment**
Create `frontend/.env`:
```env
VITE_API_URL=http://localhost:8000
```

7. **Start Frontend Server**
```bash
npm run dev
```
Frontend runs at: http://localhost:5173

8. **Seed Default Achievements**
Visit http://localhost:8000/docs and execute: `POST /api/achievements/seed`

## 🏗️ Architecture

### Tech Stack

#### Backend
- **Framework**: FastAPI 0.109.0
- **ORM**: SQLAlchemy 2.0.25
- **Database**: SQLite (dev) / PostgreSQL (prod)
- **Authentication**: JWT with python-jose
- **AI**: Groq API (LLaMA-3.3-70B)
- **External APIs**: YouTube Data API v3, Spoonacular, Google Calendar

#### Frontend
- **Framework**: React 18.2.0 + Vite 5.0.8
- **Styling**: Tailwind CSS 3.4.0
- **State Management**: Zustand 4.4.7
- **HTTP Client**: Axios 1.6.2
- **Animations**: Framer Motion 10.16.16
- **Charts**: Recharts 2.10.3
- **Notifications**: react-hot-toast 2.4.1

```

├── Basic info (name, email, password)
├── Physical stats (age, weight, height, gender)

└── Timestamps

HealthAssessment (1-to-1 with User)
├── Medical info
├── Fitness preferences
├── Nutrition preferences
└── Lifestyle info

WorkoutPlan (many-to-one with User)
├── Plan details
└── Exercises (one-to-many)

NutritionPlan (many-to-one with User)
├── Plan details
└── Meals (one-to-many)

ProgressRecord (many-to-one with User)
├── Body metrics
├── Workout stats
└── Lifestyle data

ChatSession (many-to-one with User)
└── Message history (JSON)

Achievement
└── UserAchievement (many-to-many with User)

CalendarEvent (many-to-one with User)
```

## 🔌 API Endpoints

### Authentication
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - Login user
- `GET /api/auth/me` - Get current user

### Workout
- `POST /api/workout/generate` - Generate AI workout plan
- `GET /api/workout/current` - Get active plan
- `GET /api/workout/day/{day}` - Get exercises for specific day
- `POST /api/workout/complete` - Mark exercise as completed

### Nutrition
- `POST /api/nutrition/generate` - Generate AI nutrition plan
- `GET /api/nutrition/current` - Get active plan
- `GET /api/nutrition/day/{day}` - Get meals for specific day
- `GET /api/nutrition/grocery-list` - Get grocery list

### Progress
- `POST /api/progress/` - Create progress record
- `GET /api/progress/summary` - Get progress summary
- `GET /api/progress/charts` - Get chart data

### Chat
- `POST /api/chat/` - Send message to AROMI
- `GET /api/chat/sessions` - Get chat sessions

### Achievements
- `GET /api/achievements/my` - Get user achievements
- `GET /api/achievements/check` - Check for new achievements

[See full API documentation](API_REFERENCE.md)
